# 系统设计实战题

本章以即时通信、电商、金融、协作与 AI 平台等产品场景构造模拟系统设计练习，涵盖容量估算、架构取舍、失败场景与答题自评，适合有后端开发经验的工程师练习系统设计。公司和产品名称仅用于识别场景，不表示题目来自对应公司的真实面试，也不表示文中方案就是其内部实现。

规模、阈值和技术选型未附可核实出处时，均按练习假设理解；实际项目必须重新测量和验证。答题评分是学习用自评维度，不是公司招聘评分标准。

> **学习建议：** 先练习消息可靠性、缓存与事务等通用问题，再按目标岗位选择金融、推荐或 AI 平台专题；这里不提供未经统计的“必考率”或题目出现频率。

## 答题框架

每道题建议按以下步骤回答：

1. **需求澄清**（2 分钟）：确认 DAU/QPS 规模、核心功能边界、一致性要求
2. **规模估算**（3 分钟）：计算峰值 QPS、存储容量、带宽
3. **高层架构**（5 分钟）：画出核心组件和数据流，识别系统瓶颈
4. **核心设计**（10 分钟）：针对瓶颈展开关键技术决策，说清楚 **为什么选 A 不选 B**
5. **扩展优化**（5 分钟）：说明演进路径、容灾方案、监控指标
