# 链表

链表是训练指针操作最经典的结构。它不像数组那样支持随机访问，但在插入、删除、重排时更灵活，因此是面试里非常高频的线性结构专题。

## 概念

- 链表题的核心不是随机访问，而是节点之间的连接关系。
- 这类题通常不是在“算”，而是在“改 next 指针”。
- 面试里常见的是删除、插入、反转、分段处理和快慢指针定位。

## 怎么处理

1. 先画出当前节点、前驱节点、后继节点分别是谁。
2. 如果可能动到头节点，先判断要不要加虚拟头节点。
3. 改指针之前先保存后继，避免链表断掉。
4. 如果题目涉及“中点、环、倒数第 k 个”，优先想快慢指针。
