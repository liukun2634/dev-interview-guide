# 链表

链表是训练指针操作最经典的结构。它不像数组那样支持随机访问，但在插入、删除、重排时更灵活，因此是面试里非常高频的基础专题。

## 这一类重点学什么

| 方向 | 关键能力 |
|------|------|
| 指针重连 | 能安全地修改 next 指针 |
| 虚拟头节点 | 降低头节点特殊处理复杂度 |
| 快慢指针 | 找中点、找环、定位相对位置 |
| 反转与分段 | 反转链表、分组反转、合并链表 |
