# 链表基础

<span class="dig-tag dig-tag--category">链表</span> <span class="dig-tag dig-tag--easy">⭐ 基础</span> <span class="dig-tag dig-tag--hot">🔥 高频</span>

::: tip 💡 核心要点
链表题的难点往往不是算法，而是细节：当前节点、前驱节点、后继节点分别是谁，修改顺序对不对。只要指针关系想清楚，代码通常不会太长。
:::

## 链表题的统一框架

1. 是否需要虚拟头节点。
2. 当前操作是删除、插入、反转还是查找。
3. 修改指针前，是否先保存后继节点。

## 高频技巧

- 虚拟头节点：处理删除头节点最稳定。
- 快慢指针：找中点、判断环、找环入口。
- 原地反转：维护 `prev`、`curr`、`next` 三个指针。

## 易错点

1. 改指针顺序错误，导致链表断开。
2. 漏掉头节点特殊情况。
3. 只会写代码，不会解释快慢指针为什么有效。
