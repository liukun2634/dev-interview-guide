# 链表题处理框架

<span class="dig-tag dig-tag--category">链表</span> <span class="dig-tag dig-tag--easy">⭐ 入门</span> <span class="dig-tag dig-tag--hot">🔥 高频</span>

::: tip 💡 核心要点
链表题的难点往往不是算法，而是细节：当前节点、前驱节点、后继节点分别是谁，修改顺序对不对。只要指针关系想清楚，代码通常不会太长。
:::

## 概念

- 链表题的核心是节点连接关系，不是数组下标。
- 很多错误都不是算法错，而是改指针时顺序错了。
- 只要把前驱、当前、后继三者关系画清楚，大部分题都能稳定落地。

## 怎么处理

1. 先判断操作类型：删除、插入、反转、查找还是分段处理。
2. 会动到头节点时，优先考虑虚拟头节点。
3. 修改 `next` 前先保存后继节点。
4. 涉及相对位置、中点、环时，优先考虑快慢指针。
