# 取模与快速幂

<span class="dig-tag dig-tag--category">基础知识</span> <span class="dig-tag dig-tag--intermediate">⭐⭐ 中级</span> <span class="dig-tag dig-tag--hot">🔥 高频</span>

::: tip 💡 核心要点
很多计数类题目答案巨大，会要求 **对 `10^9 + 7` 取模**。核心是记住：**加减乘可以随时取模、除法不能**（要用逆元）。配套技能是**快速幂**（$O(\log n)$ 求 $a^b$）。掌握"边算边取模 + 快速幂 + 逆元"三件套，就能应付面试里绝大多数取模题。
:::

## 一、为什么要取模？

面试/竞赛里的计数题（方案数、路径数、组合数）答案会**指数级增长**，远超 `long` 甚至 `__int128` 能表示的范围。

```
斐波那契第 100 项 ≈ 3.5 × 10^20  → 已经溢出 long（上限约 9.2 × 10^18）
爬楼梯 n=1000 的方案数 → 几百位的天文数字
```

**解决办法**：题目规定"答案对某个大质数 $M$（通常是 $10^9+7$）取模"，让每一步中间结果都保持在 $[0, M)$ 范围内，永不溢出。你输出的是 $\text{answer} \bmod M$，而不是真实的巨大值。

::: warning ⚠️ 为什么偏偏是 $10^9 + 7$？

> ① **它是质数**——保证任何非零数都存在**乘法逆元**（除法取模的前提），且不会出现"和 M 有公因子导致取模后为 0"的坑。
> ② **足够大**——$10^9+7 < 2^{30}$，两个模内的数相乘 $< 10^{18} < 2^{63}$，**用 `long` 存中间乘积不会溢出**。
> ③ 另一个常见模数是 $998244353$，它是 **NTT 友好质数**（$= 119 \times 2^{23} + 1$），做多项式/卷积时用。

:::

## 二、取模的核心运算法则

取模对**加、减、乘**满足分配律，可以"边算边取模"；但**除法不行**。

$$
(a + b) \bmod M = ((a \bmod M) + (b \bmod M)) \bmod M
$$

$$
(a \times b) \bmod M = ((a \bmod M) \times (b \bmod M)) \bmod M
$$

| 运算 | 能否直接取模 | 说明 |
|------|:---:|------|
| 加法 `a + b` | ✅ | 先各自取模再相加，结果再取模 |
| 减法 `a - b` | ✅ | **可能出负**，要 `(a - b + M) % M` |
| 乘法 `a * b` | ✅ | 中间积可能溢出，用 `long` 存 |
| 除法 `a / b` | ❌ | **不能直接取模**，要乘 `b` 的逆元 |

### 两个必背的坑

```java
final int MOD = 1_000_000_007;

// 坑 1：减法出负数 → 加 MOD 再取模
int sub = (int)(((a - b) % MOD + MOD) % MOD);

// 坑 2：乘法溢出 → 先转 long 再乘再取模
int mul = (int)((long) a * b % MOD);   // a、b 都是 int，(long)a * b 才不溢出
```

::: danger 🔴 最常见的 WA 原因
`int a, b;` 时写 `a * b % MOD`——`a * b` 在取模前就已经 **int 溢出**了！必须写成 `(long) a * b % MOD`。这是取模题第一大暗坑。
:::

## 三、快速幂（Fast Power / 二分幂）

### 它解决什么

求 $a^b \bmod M$。朴素做法循环乘 $b$ 次是 $O(b)$，当 $b = 10^{18}$ 时根本算不完。**快速幂用二进制拆分指数，把复杂度降到 $O(\log b)$。**

### 原理

把指数 $b$ 写成二进制，例如 $a^{13} = a^{1101_2} = a^8 \cdot a^4 \cdot a^1$。从低位到高位扫描 $b$ 的每一位，底数不断自乘（$a \to a^2 \to a^4 \to \dots$），遇到该位是 1 就把当前底数累乘进结果。

```
求 a^13:  13 = 1101(二进制)
  bit0=1: res *= a^1  ; base = a^2
  bit1=0:             ; base = a^4
  bit2=1: res *= a^4  ; base = a^8
  bit3=1: res *= a^8  ; 结束
  → res = a^1 · a^4 · a^8 = a^13  ✅
```

### 模板（必背）

```java
long qpow(long a, long b, long mod) {
    long res = 1;
    a %= mod;                    // 先把底数收进模内
    while (b > 0) {
        if ((b & 1) == 1) {      // 当前二进制位是 1
            res = res * a % mod;
        }
        a = a * a % mod;         // 底数平方
        b >>= 1;                 // 指数右移一位
    }
    return res;
}
```

> **复杂度** $O(\log b)$。这个模板是取模题的通用基础件，逆元、组合数取模都建立在它之上。

## 四、除法取模：乘法逆元

### 为什么除法不能直接取模

$(a / b) \bmod M \ne ((a \bmod M) / (b \bmod M)) \bmod M$。除法会破坏取模的整除关系，必须转化为**乘以 $b$ 的乘法逆元** $b^{-1}$：

$$
\frac{a}{b} \bmod M = a \times b^{-1} \bmod M
$$

其中 $b^{-1}$ 满足 $b \times b^{-1} \equiv 1 \pmod M$。

### 费马小定理求逆元（模数是质数时）

当 $M$ 是质数且 $b$ 不是 $M$ 的倍数时，由费马小定理 $b^{M-1} \equiv 1 \pmod M$，得：

$$
b^{-1} \equiv b^{M-2} \pmod M
$$

**所以逆元 = 快速幂算 $b^{M-2}$**：

```java
long inverse(long b, long mod) {   // mod 必须是质数
    return qpow(b, mod - 2, mod);
}

// 计算 (a / b) % MOD
long divMod(long a, long b, long mod) {
    return a % mod * inverse(b, mod) % mod;
}
```

> 若模数**不是质数**，费马小定理失效，要用**扩展欧几里得**求逆元（存在条件是 $\gcd(b, M) = 1$）。

## 五、组合数取模（高频应用）

计数题常要算 $C(n, k) \bmod M = \dfrac{n!}{k!\,(n-k)!} \bmod M$。分母是除法，必须用逆元。

```java
final int MOD = 1_000_000_007;
long[] fact, invFact;

void init(int n) {
    fact = new long[n + 1];
    invFact = new long[n + 1];
    fact[0] = 1;
    for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % MOD;
    invFact[n] = qpow(fact[n], MOD - 2, MOD);          // 阶乘逆元一次算出
    for (int i = n; i > 0; i--) invFact[i - 1] = invFact[i] * i % MOD;  // 递推回去
}

long comb(int n, int k) {
    if (k < 0 || k > n) return 0;
    return fact[n] * invFact[k] % MOD * invFact[n - k] % MOD;
}
```

> **技巧**：只需一次快速幂算出 $\text{fact}[n]$ 的逆元，再**倒推**出所有 $\text{invFact}[i]$（$invFact[i-1] = invFact[i] \times i$），预处理 $O(n)$，单次查询 $O(1)$。

## 六、其他常见"取模/数论"要求

### 1. 大数取模（逐位霍纳法）

字符串表示的超大数对 $M$ 取模，逐位累加：

```java
int bigMod(String num, int mod) {
    int res = 0;
    for (char c : num.toCharArray())
        res = (res * 10 + (c - '0')) % mod;   // 霍纳法则，边读边取模
    return res;
}
```

### 2. 取模的负数问题（跨语言差异）

| 语言 | `-7 % 3` 结果 | 说明 |
|------|:---:|------|
| Java / C++ | **-1** | 结果符号跟**被除数**，可能为负 |
| Python | **2** | 结果符号跟**除数**，恒非负 |

> Java/C++ 里凡是可能出负的取模，统一写 `((x % M) + M) % M` 规范到 $[0, M)$。

### 3. 哈希取模（工程/算法都用）

- **哈希表容量取 2 的幂** → 用 `hash & (n-1)` 代替 `hash % n`（位运算快 10 倍，详见 [哈希表](../hash-table)）。
- **字符串滚动哈希（Rabin-Karp）** → 用大质数模数减少冲突。

### 4. 快速幂的变体：快速乘

当模数接近 $2^{63}$，连 `long` 相乘都溢出时，用**快速乘**（把乘法拆成加法的二分，同快速幂思路）或直接上 `__int128`（C++）/ `Math.multiplyHigh`（Java）。

## 面试常问 & 怎么答

**Q1：为什么计数题要对 $10^9+7$ 取模？**

因为答案指数级增长会溢出。$10^9+7$ 是质数（保证逆元存在），且两个模内数相乘小于 $2^{63}$（用 long 存不溢出）。取模后每一步保持在 $[0, M)$，输出的是答案 mod M。

**Q2：加减乘都能取模，为什么除法不行？怎么办？**

取模对加减乘满足分配律，可边算边取模；除法会破坏整除关系。要把 $a/b$ 转成 $a \times b^{-1}$，其中 $b^{-1}$ 是 $b$ 的乘法逆元。模数为质数时用费马小定理 $b^{-1} = b^{M-2}$（快速幂求），否则用扩展欧几里得。

**Q3：快速幂的原理和复杂度？**

把指数写成二进制，从低位扫到高位，底数不断平方，遇到 1 的位就累乘进结果，$a^{13}=a^8·a^4·a^1$。复杂度 $O(\log b)$，相比朴素 $O(b)$ 大幅优化。

**Q4：取模题最容易 WA 的地方？**

① int 乘法在取模前就溢出——必须 `(long)a * b % MOD`；② 减法结果为负——要 `(a - b + MOD) % MOD`；③ Java/C++ 负数取模结果为负，需规范到 $[0, M)$。

## 看到什么就先想到这类

- 题目出现"**答案对 $10^9+7$ / $998244353$ 取模**" → 计数题，边算边取模 + 快速幂
- 出现"**求 $a^b$ / 幂 / 次方**且 b 很大" → 快速幂 $O(\log b)$
- 出现"**除以 / 组合数 $C(n,k)$ / 阶乘**且要取模" → 乘法逆元（费马小定理）
- 出现"**超大数（字符串）取模**" → 霍纳法逐位取模
- 出现"**结果可能为负数**" → `((x % M) + M) % M`
