# 基础方法

这一部分不属于某一种具体数据结构，但它决定了你后续能不能稳定地分析题目。正规的学习路径里，复杂度、递归、递推应该先于大量刷题出现。

## 这一类重点学什么

| 能力点 | 说明 |
|------|------|
| 复杂度分析 | 能判断时间复杂度、空间复杂度和优化方向 |
| 递归思维 | 能把问题拆成结构相同的子问题 |
| 递推意识 | 能从子问题答案推到原问题 |
| 分析语言 | 能明确描述状态、边界、循环不变量 |

## 学习建议

如果这部分没打好，后面的树、搜索、动态规划会学得很碎。先把“如何分析”练清楚，再看“如何实现”。
