# 区间 DP

<span class="dig-tag dig-tag--category">动态规划</span> <span class="dig-tag dig-tag--hard">⭐⭐⭐ 进阶</span> <span class="dig-tag dig-tag--hot">🔥 高频</span>

::: tip 💡 核心要点
区间 DP 适合“一个区间的答案由更短区间推出”的问题。常见特征是枚举区间长度，再枚举左右边界或分割点。
:::

## 典型状态

`dp[l][r]` 表示区间 `[l, r]` 上的最优答案。

## 常见转移方式

1. 按最后一步划分。
2. 按分割点 `k` 把区间拆成左右两部分。
3. 先算短区间，再算长区间。

## 代表题型

| 题型 | 代表题 |
|------|------|
| 回文区间 | 最长回文子序列 |
| 合并型问题 | 石子合并 |
| 分割型问题 | 戳气球 |
