# 动态规划

动态规划的核心不是套模板，而是把原问题拆成一组**有重叠子问题的状态**，再通过状态转移把答案逐步推出来。

## 动态规划总框架

1. 定义状态：`dp[i]` 或 `dp[i][j]` 表示什么。
2. 写转移方程：当前答案由哪些更小状态推出。
3. 确定初始值：最小子问题的答案是什么。
4. 决定遍历顺序：保证转移依赖的状态已经算出来。

## 当前专题结构

| 二级专题 | 关注点 |
|------|------|
| [线性 DP](./linear-dp) | 一维或二维顺序推进的状态设计 |
| [区间 DP](./interval-dp) | 一个区间如何由更短区间推出 |
| [树形 DP](./tree-dp) | 把节点当状态，在子树间做转移 |
| [状态压缩 DP](./state-compression-dp) | 用二进制集合表示选取状态 |
| [典型动态规划问题](./classic-problems) | 从题型角度整理高频题套路 |

## 学习建议

先学线性 DP，把状态定义说清楚；再学区间 DP，理解“更短区间推出更长区间”的思路；然后看树形 DP，最后学习状态压缩 DP，建立集合型状态的意识。
