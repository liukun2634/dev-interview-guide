# 动态规划

动态规划的核心不是套模板，而是把原问题拆成一组**有重叠子问题的状态**，再通过状态转移把答案逐步推出来。

## 概念

- 动态规划解决的是“子问题会重复出现，而且可以复用”的问题。
- 核心不是记公式，而是先定义状态：`dp` 到底表示什么。
- 一旦状态定义错了，后面的转移、初始化、遍历顺序都会跟着错。

## 怎么处理

1. 先定义状态，明确 `dp[i]` 或 `dp[i][j]` 的含义。
2. 再写转移，说明当前状态依赖哪些更小状态。
3. 然后补初始化，处理最小子问题。
4. 最后确定遍历顺序，保证依赖先算出来。

## 看到什么就先想到这类

- 出现“最优值、方案数、是否可达”。
- 出现“当前答案依赖之前若干状态”。
- 暴力递归能写出来，但有大量重复计算。
