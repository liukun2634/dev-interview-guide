# 典型动态规划问题

<span class="dig-tag dig-tag--category">动态规划</span> <span class="dig-tag dig-tag--medium">⭐⭐ 中级</span> <span class="dig-tag dig-tag--hot">🔥 高频</span>

::: tip 💡 核心要点
面试里很多动态规划题并不是完全新的，它们通常落在少数几类题型里：**线性选择、背包、区间 DP、序列匹配、树形 DP**。学会按题型归类，比死记题目更重要。
:::

## 高频题型地图

| 题型 | 识别信号 | 代表问题 |
|------|------|------|
| 线性选择 | 每个位置选或不选 | 打家劫舍、爬楼梯 |
| 背包问题 | 容量约束 + 价值最优 | 0/1 背包、完全背包 |
| 区间 DP | 一个区间由更短区间推出 | 戳气球、回文子串 |
| 序列 DP | 两个字符串或数组匹配 | LCS、编辑距离 |
| 树形 DP | 子树合并 | 打家劫舍 III |

## 典型问题拆法

### 打家劫舍

- 状态：到第 `i` 间房的最大收益。
- 决策：偷当前房子还是不偷。

### 最长公共子序列

- 状态：`dp[i][j]` 表示两个前缀的最优答案。
- 决策：当前字符相等时继承对角线，否则从上或左转移。

### 0/1 背包

- 状态：前 `i` 个物品、容量 `j` 时的最大价值。
- 决策：选当前物品还是不选。

## 复习建议

1. 不要直接背答案，先口述状态定义。
2. 再写出转移依赖的更小问题。
3. 最后检查初始化和遍历顺序。

如果一道题你能用这三步讲清楚，基本就能写对。
