# 回溯

<span class="dig-tag dig-tag--category">图与搜索</span> <span class="dig-tag dig-tag--medium">⭐⭐ 中级</span> <span class="dig-tag dig-tag--hot">🔥 高频</span>

::: tip 💡 核心要点
回溯的本质是沿着决策树做 DFS：做选择、递归、撤销选择。全排列、组合、子集、棋盘搜索题，大多都可以统一进这个框架。
:::

## 标准模板

1. 路径 `path` 表示当前已经做出的选择。
2. 选择列表表示下一步还能选什么。
3. 终止条件决定什么时候收集答案。
4. 返回前撤销当前选择。

## 常见题型

| 题型 | 代表问题 |
|------|------|
| 子集 | 子集、幂集 |
| 排列 | 全排列、含重复元素的排列 |
| 组合 | 组合总和、k 个数的组合 |
| 棋盘搜索 | N 皇后、单词搜索 |
