# 图与搜索

图与搜索这一部分负责训练“状态空间”的思维。二叉树是特殊的图，回溯是特殊的搜索，二分是有序空间上的搜索方式。把这些放在一起学，更容易建立统一的搜索视角。

## 这一类重点学什么

| 方向 | 关键能力 |
|------|------|
| 图建模 | 节点、边、邻接关系如何表示 |
| 遍历搜索 | DFS、BFS 的适用场景 |
| 二分查找 | 在有序空间中缩小答案范围 |
| 回溯 | 在决策树中枚举所有可能 |

## 当前专题

| 二级专题 | 核心问题 |
|------|------|
| [图基础](./graph-basics) | 图如何建模，DFS/BFS 如何遍历 |
| [BFS 与 DFS](./bfs-dfs) | 什么时候按层扩展，什么时候深度递归 |
| [二分查找](./binary-search) | 有序数组和答案空间的二分套路 |
| [拓扑排序](./topological-sort) | 有向无环图中的依赖顺序如何求解 |
| [最短路](./shortest-path) | 从 BFS 到 Dijkstra，如何求最短距离 |
| [回溯](./backtracking) | 全排列、子集、组合类题如何统一处理 |

## 学习建议

先学 [图基础](./graph-basics) 和 [BFS 与 DFS](./bfs-dfs)，再学 [二分查找](./binary-search) 这种特殊搜索；之后补 [拓扑排序](./topological-sort) 与 [最短路](./shortest-path)，最后再系统看 [回溯](./backtracking)。
