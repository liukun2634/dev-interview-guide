# 二分查找

<span class="dig-tag dig-tag--category">图与搜索</span> <span class="dig-tag dig-tag--easy">⭐ 基础</span> <span class="dig-tag dig-tag--hot">🔥 高频</span>

::: tip 💡 核心要点
二分查找不只是“在有序数组里找某个数”，更重要的是识别“答案具有单调性”，然后在答案空间里二分。
:::

## 经典二分框架

1. 明确左右边界。
2. 写清楚 `mid` 的计算方式。
3. 判断保留左边还是右边。
4. 最后确认边界语义。

## 常见题型

- 有序数组查找。
- 查找第一个/最后一个满足条件的位置。
- 答案空间二分，例如最小可行值、最大可行值。

## 易错点

1. 区间是左闭右闭还是左闭右开没有统一。
2. 循环结束条件和返回值对应不上。
3. 只会“找数”，不会“二分答案”。
