# 位运算技巧

<span class="dig-tag dig-tag--category">贪心与技巧</span> <span class="dig-tag dig-tag--medium">⭐⭐ 中级</span> <span class="dig-tag dig-tag--hot">🔥 高频</span>

::: tip 💡 核心要点
位运算的价值不在于炫技，而在于它能把集合、奇偶性、去重、状态切换压缩成常数级操作。
:::

## 高频操作

- `x & 1`：判断奇偶。
- `x & (x - 1)`：去掉最低位的 1。
- `x ^ x = 0`：异或去重。
- `1 << k`：表示第 `k` 位。

## 常见应用

| 场景 | 用法 |
|------|------|
| 集合表示 | 状态压缩 |
| 奇偶判断 | 最低位判断 |
| 去重问题 | 异或性质 |
| 枚举子集 | 位掩码遍历 |
