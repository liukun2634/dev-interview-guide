# 贪心与技巧

这一部分放的是“题感型”能力：贪心、位运算，以及一些靠局部性质或表示技巧降复杂度的方法。它们不像动态规划那样统一，但在面试里很高频。

## 这一类重点学什么

| 方向 | 关键能力 |
|------|------|
| 贪心 | 证明局部最优能推出全局最优 |
| 位运算 | 用二进制表示状态、快速做按位操作 |
| 技巧意识 | 把题目从直观写法压缩成更高效表达 |

| 二级专题 | 核心问题 |
|------|------|
| [贪心算法](./greedy) | 如何判断题目能否贪心，以及常见证明方式 |
| [位运算技巧](./bitwise) | 与、或、异或、移位在算法题中的应用 |
