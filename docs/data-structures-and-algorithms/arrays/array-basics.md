# 线性扫描与区间处理

<span class="dig-tag dig-tag--category">数组与字符串</span> <span class="dig-tag dig-tag--easy">⭐ 入门</span> <span class="dig-tag dig-tag--hot">🔥 高频</span>

::: tip 💡 核心要点
数组与字符串题的关键不是记住某一道题，而是先建立统一框架：**遍历顺序、区间定义、辅助信息、边界处理**。只要这四步清楚，很多线性结构题都能快速归类。
:::

## 概念

- 这类题的核心是元素排成一条线，信息通常从左到右维护。
- 常见问题可以拆成三种：单点扫描、连续区间、区间统计。
- 只要先判断自己在处理哪一种，方法就会收敛得很快。

## 怎么处理

1. 先看题目是不是围绕连续区间展开。
2. 如果有左右边界一起移动，优先考虑双指针或滑动窗口。
3. 如果要快速求区间和、区间次数，优先考虑前缀和。
4. 如果要求原地修改，就明确快慢指针分别维护什么。

## 典型实例

| 场景 | 先想什么 | 典型题 |
|------|------|------|
| 有序数组去重 | 快慢指针 | 删除有序数组中的重复项 |
| 最长或最短连续区间 | 滑动窗口 | 最长无重复子串、长度最小子数组 |
| 任意区间和统计 | 前缀和 | 和为 K 的子数组 |
| 批量区间增减 | 差分 | 航班预订统计 |

这些实例适合先建立分类感觉，再进入 [双指针](./two-pointers)、[滑动窗口](./sliding-window)、[前缀和与差分](./prefix-sum-difference) 做展开。
