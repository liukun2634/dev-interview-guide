# 滑动窗口

<span class="dig-tag dig-tag--category">数组与字符串</span> <span class="dig-tag dig-tag--medium">⭐⭐ 中级</span> <span class="dig-tag dig-tag--hot">🔥 高频</span>

::: tip 💡 核心要点
滑动窗口是“双指针在连续区间问题上的特化形式”。它适合处理最长、最短、计数类连续子数组或子串问题，本质是维护一个动态区间，并在扩张和收缩中保持条件成立。
:::

## 标准模板

1. 右指针右移，把新元素加入窗口。
2. 如果窗口不满足条件，就移动左指针收缩窗口。
3. 在窗口满足条件时更新答案。

## 适用信号

- 题目要求“连续子数组”或“连续子串”。
- 要找最长或最短满足条件的区间。
- 区间条件可以随着左右边界变化在线维护。
