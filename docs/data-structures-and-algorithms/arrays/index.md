# 数组与字符串

数组与字符串是线性结构训练的核心入口。字符串题在实现上往往也会转成数组遍历，因此这两类通常放在一起学习。

## 这一类重点学什么

| 能力点 | 典型方法 | 适用场景 |
|------|------|------|
| 顺序扫描 | 单次遍历、双指针 | 有序数组、去重、区间收缩 |
| 区间统计 | 前缀和、差分 | 子数组和、批量区间更新 |
| 局部最优维护 | 滑动窗口 | 最长/最短满足条件区间 |
| 原地修改 | 双指针、交换 | 原地删除、分区、旋转 |

| 二级专题 | 核心问题 |

## 学习建议

1. 先学 [数组与字符串基础](./array-basics)，建立统一分析框架。
2. 再学 [双指针](./two-pointers) 和 [滑动窗口](./sliding-window)，掌握最常见线性扫描优化。
3. 如果题目涉及区间统计或批量更新，再进入 [前缀和与差分](./prefix-sum-difference)。
