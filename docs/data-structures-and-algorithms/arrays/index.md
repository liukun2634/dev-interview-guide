# 数组与字符串

数组与字符串是线性结构训练的核心入口。字符串题在实现上往往也会转成数组遍历，因此这两类通常放在一起学习。

## 概念

- 这一类题主要处理顺序扫描、连续区间、字符统计和原地修改。
- 数组和字符串的共同点是元素排成一条线，很多题的重点都在“从左到右怎么维护信息”。
- 面试里只要出现子数组、子串、左右边界、区间和、去重，通常都要先想这一类方法。

## 怎么处理

1. 先判断问题是单点扫描还是连续区间。
2. 如果是左右边界一起移动，优先想双指针或滑动窗口。
3. 如果是快速求区间信息，优先想前缀和；如果是批量区间更新，再想差分。
4. 如果要求原地修改，就明确哪些位置已经处理完、哪些位置还没处理。
