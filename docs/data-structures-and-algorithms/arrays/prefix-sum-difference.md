# 前缀和与差分

<span class="dig-tag dig-tag--category">数组与字符串</span> <span class="dig-tag dig-tag--medium">⭐⭐ 中级</span> <span class="dig-tag dig-tag--hot">🔥 高频</span>

::: tip 💡 核心要点
前缀和解决的是“如何快速求任意区间和”，差分解决的是“如何高效做批量区间更新”。这两者是数组区间问题最重要的两个工具。
:::

## 前缀和

定义：`prefix[i]` 表示前 `i` 个元素之和。

则任意区间 `[l, r]` 的和可以写成：

$$
sum(l, r) = prefix[r + 1] - prefix[l]
$$

### 常见应用

- 子数组和问题。
- 二维矩阵区域和。
- 前缀状态配合哈希表做统计。

## 差分

定义：`diff[i] = nums[i] - nums[i - 1]`。

当要给区间 `[l, r]` 同时加上一个值 `x` 时，只需要：

- `diff[l] += x`
- `diff[r + 1] -= x`

最后再还原原数组。

## 高频题型

| 技术 | 代表题 |
|------|------|
| 前缀和 | 和为 K 的子数组 |
| 二维前缀和 | 二维区域和检索 |
| 差分 | 航班预订统计、区间加法 |
