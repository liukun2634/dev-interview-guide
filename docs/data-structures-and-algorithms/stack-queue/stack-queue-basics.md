# 栈与队列基础

<span class="dig-tag dig-tag--category">栈与队列</span> <span class="dig-tag dig-tag--easy">⭐ 基础</span> <span class="dig-tag dig-tag--hot">🔥 高频</span>

::: tip 💡 核心要点
栈适合处理“最近、配对、回退”类关系；队列适合处理“按层、按时间、按先后”推进的问题。识别出顺序模型，题目就会简单很多。
:::

## 如何判断用栈还是队列

- 如果问题关注“最近一个未处理元素”，优先想栈。
- 如果问题关注“按进入顺序逐层扩展”，优先想队列。

## 常见题型

| 结构 | 典型题型 |
|------|------|
| 栈 | 有效括号、逆波兰表达式、单调栈 |
| 队列 | 层序遍历、BFS、滑动窗口最大值 |

## 进阶方向

1. 单调栈：维护一个有顺序约束的栈。
2. 单调队列：在窗口移动中维护最大值或最小值。
3. BFS：队列在图和树上的层级遍历应用。
