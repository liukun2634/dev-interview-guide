# 顺序结构处理框架

<span class="dig-tag dig-tag--category">栈与队列</span> <span class="dig-tag dig-tag--easy">⭐ 入门</span> <span class="dig-tag dig-tag--hot">🔥 高频</span>

::: tip 💡 核心要点
栈适合处理“最近、配对、回退”类关系；队列适合处理“按层、按时间、按先后”推进的问题。识别出顺序模型，题目就会简单很多。
:::

## 概念

- 栈和队列都在维护顺序，只是维护的顺序不同。
- 栈处理“最近、回退、配对”，队列处理“推进、扩展、按层”。
- 当题目要求在线维护最值时，又会衍生出单调栈和单调队列。

## 怎么处理

1. 先判断当前题目是要回退、配对，还是要推进、扩展。
2. 回退或最近关系优先想栈，层次推进优先想队列。
3. 如果每个元素只想进出一次并维护有序性，就继续想单调结构。

## 典型实例

| 结构 | 代表题型 |
|------|------|
| 栈 | 有效括号、逆波兰表达式、最近更大元素 |
| 队列 | 层序遍历、BFS、最短步数 |
| 单调队列 | 滑动窗口最大值 |

这几类例子足够覆盖“顺序信息怎么维护”这个核心问题。
