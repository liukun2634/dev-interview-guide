# 栈与队列

栈与队列是最基础的抽象数据结构之一。它们看起来简单，但会进一步引出单调栈、单调队列、BFS 等更重要的算法套路。

## 这一类重点学什么

| 方向 | 典型问题 |
|------|------|
| 栈 | 括号匹配、表达式计算、最近更大元素 |
| 队列 | 层序遍历、BFS、滑动窗口 |
| 单调结构 | 每个元素只进出一次的线性优化 |

## 学习建议

学这一类时，不要只记“栈是后进先出、队列是先进先出”，更要想清楚它们维护了什么顺序信息。
