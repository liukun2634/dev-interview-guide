# 树与堆

树与堆都属于非线性结构。树强调递归、层级关系和子问题建模；堆强调“局部最值”的快速维护。它们经常出现在遍历、搜索、优先级调度和 top-k 问题里。

## 这一类重点学什么

| 方向 | 核心方法 | 常见问题 |
|------|------|------|
| 树遍历 | 前序、中序、后序、层序 | 输出、搜索、序列化 |
| 递归设计 | 定义子问题与返回值 | 深度、直径、平衡性 |
| 路径问题 | 自顶向下 / 自底向上 | 路径和、最近公共祖先 |
| 树形 DP | 节点状态转移 | 打家劫舍 III、树上最优选择 |
| 堆结构 | push、pop、heapify | top-k、合并有序流、优先队列 |
