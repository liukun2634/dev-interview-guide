# 堆与优先队列

<span class="dig-tag dig-tag--category">树与堆</span> <span class="dig-tag dig-tag--medium">⭐⭐ 中级</span> <span class="dig-tag dig-tag--hot">🔥 高频</span>

::: tip 💡 核心要点
堆是一种完全二叉树结构，核心能力是快速维护当前最大值或最小值。凡是出现 top-k、优先调度、动态维护最值，优先考虑堆。
:::

## 核心性质

- 大根堆：父节点大于等于子节点。
- 小根堆：父节点小于等于子节点。
- 插入和删除堆顶通常都是 $O(\log n)$。

## 典型应用

| 场景 | 常见问题 |
|------|------|
| top-k | 数组中第 k 大元素 |
| 多路合并 | 合并 k 个有序链表 |
| 调度问题 | 任务优先执行、最小代价选择 |

## 学习建议

堆题不要和排序题混淆。堆排序是一种应用，但面试里更高频的是“动态维护堆顶”。
