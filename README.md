# 程序员面试手册

系统化的程序员面试知识体系，涵盖算法、系统设计、数据库等 **9 大领域**，助你高效备战技术面试。

## 在线阅读

**https://liukun2634.github.io/dev-interview-guide/**

## 知识领域

| 领域 | 内容 |
|------|------|
| 数据结构与算法 | 二叉树、哈希表等 |
| 操作系统 | 进程与线程等 |
| 计算机网络 | TCP 与 UDP 等 |
| 数据库 | 索引原理等 |
| 系统设计 | 缓存策略、限流与熔断、消息队列、微服务架构 |
| 工程实践 | 分布式 ID 生成、Docker 容器化 |
| 编程语言 | Java 基础等 |
| Web 与框架 | RESTful API 等 |
| AI 技术 | LLM 基础、RAG、Prompt Engineering、AI Agent |

## AI 驱动

本项目的内容和网站设计均由 **AI 辅助生成**，包括文章撰写、代码实现和 UI 设计。这是一次 AI 与人类协作的实践 —— 用 AI 的效率结合人的判断，快速构建高质量的知识体系。

## 参与贡献

欢迎使用 AI 工具（如 Claude、ChatGPT、Cursor 等）帮助撰写和提交内容！

**贡献方式：**

1. Fork 本仓库
2. 使用 AI 辅助撰写某个知识领域的文章
3. 提交 PR，在 commit message 中标注 AI 协作信息

无论是补充新领域的内容、完善现有文章，还是修复错误，都非常欢迎。
