# Dev Interview Guide

系统化的程序员面试知识体系，涵盖算法、系统设计、数据库等 8 大领域。

## 在线访问

https://liukun2634.github.io/dev-interview-guide/

## 知识领域

- **数据结构与算法** - 二叉树、哈希表等
- **操作系统** - 进程与线程等
- **计算机网络** - TCP 与 UDP 等
- **数据库** - 索引原理等
- **系统设计** - 缓存策略等
- **编程语言** - Java 基础等
- **Web 与框架** - RESTful API 等
- **DevOps** - Docker 容器化等

## 本地开发

```bash
# 安装依赖
```
