不是零散题解的堆叠，而是把每个主题整理成一条清晰路径：**概念原理 → 关键区别 → 代码实战 → 高频追问**，方便你在准备面试时快速查阅和反复复习。

## ✨ 特点

- 🗂️ **9 大领域**覆盖程序员面试高频知识面，含独立成体系的 AI 技术专题
- 🛤️ **复习路径导向**，不是资料堆砌，每个章节有决策树和学习顺序
- 💻 **Java 代码驱动**，算法专题含通用模板 + LeetCode 例题完整题解
- 🔍 **全站搜索**，收藏后可以随时按主题检索和回看
- 📱 **移动端适配**，通勤路上也能复习

## 📚 知识覆盖

| 领域 | 代表主题 |
|:------|:------|
| **🤖 AI 技术** | LLM 原理、Prompt Engineering、RAG、Embedding、向量数据库、AI Agent、推理优化、AI 面试准备 |
| **📊 数据结构与算法** | 数组与字符串、链表、栈与队列、哈希、树、图搜索、动态规划、贪心 |
| **☕ 编程语言** | Java 基础、集合框架、JVM、并发编程、Spring 核心 |
| **🗄️ 数据库** | MySQL 索引、事务与锁、分库分表、日志系统、Redis |
| **🌐 计算机网络** | TCP/UDP、HTTP/HTTPS、DNS、WebSocket、网络安全、CDN |
| **💻 操作系统** | 进程与线程、内存管理、文件与 IO、Linux 常用命令 |
| **🏗️ 系统设计** | 分布式理论、CAP/BASE、缓存策略、限流熔断、消息队列、微服务 |

| **🌍 Web 与框架** | Spring MVC、RESTful API、Spring Boot 自动配置 |

- 准备**后端、全栈**方向技术面试的工程师

- 想边阅读边补充，把面试笔记沉淀成**公开仓库**的人

## 🚀 快速开始

```bash
# 克隆仓库
git clone https://github.com/liukun2634/dev-interview-guide.git
cd dev-interview-guide

# 安装依赖
npm install

# 本地开发
npm run docs:dev

# 生成静态站点
npm run docs:build
```
