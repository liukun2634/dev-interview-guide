# 程序员面试手册

一个面向程序员技术面试的系统化知识库，覆盖算法、系统设计、数据库、AI 等 **9 大领域**。

它不是零散题解的堆叠，而是尽量把每个主题整理成一条清晰路径：**概念原理 -> 关键区别 -> 高频追问 -> 延伸阅读**，方便你在准备面试时快速查阅和反复复习。

## 适合谁使用

- 正在准备后端、全栈、基础设施或平台方向技术面试的人。
- 想把零散八股整理成一套可持续复习知识库的人。
- 想系统补齐 AI 面试基础，而不是只看零散术语解释的人。
- 想边阅读边补充内容，把自己的面试笔记沉淀成公开仓库的人。

## 快速开始

```bash
# 安装依赖
npm install

# 本地开发
npm run docs:dev

# 生成静态站点
npm run docs:build

# 本地预览构建结果
npm run docs:preview
```

## 参与贡献

欢迎通过 Issue 或 PR 一起完善这个知识库。

你可以贡献：

1. 补充新的面试主题或补全现有文章。
2. 修正文案错误、概念表述不严谨或示例代码问题。
3. 增加高频追问、对比表、延伸阅读和典型易错点。
4. 优化文档结构、导航体验和阅读体验。

如果你会使用 AI 工具辅助写作也没问题，但提交前请务必自行校对事实、术语和代码示例，保证内容可信度。
